# AGENTS for Aria Grande

## About

This is an javascript based WebMCP accessibility framework for enabling AI-enabled browsers to access website structure, search, content and interactions.

## Directory structure

Three subprojects:
- `aria-grande` is the WebMCP framework
- `hello-example` is a simplified hello world example
- `shopify-example` is a complex content example using shopify
- `webmcp-resources` contains 3rd party WebMCP resources

Each project has it's own AGENTS.md
